# Host questions — pre-recorded audio

Drop the Host robot's recordings here as `<name>.wav` and name the file in the
console's **Host asks** box. The Host plays the file; Panganiban answers the
typed text live.

A clip is preferred over synthesis: the Host's voice is cloned or recorded by
hand, so a real take is both better and free. With no clip named, the Host
says the text in whatever voice `ELEVEN_HOST_VOICE_ID` points at.

The audio the Host plays and the text Panganiban answers are separate on
purpose — the recording can be a warm, conversational reading while the text
stays the precise question you want routed.

Not in git (see `.gitignore`): these are media and they are venue-specific.
